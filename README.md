# Justice for PlusToken Victims

A multilingual public appeal site. One appeal is scheduled at a random time every 8–24 hours. GitHub Actions checks every 15 minutes and publishes a due post.

## Edit posts

Open `posts.json` in the GitHub repository and choose the pencil icon. Edit a translation's `title` or `body` under `en`, `ko`, `de`, `zh`, or `ja`, then commit. Keep the JSON quotes and commas intact. The workflow runs after a commit to `main` and republishes the site.

To pause automatic publishing, disable **Publish and deploy appeals** in the repository's Actions tab.

## Search engines

The workflow creates crawlable HTML pages for every post and language, along with `sitemap.xml` and `robots.txt`. Add the site to Google Search Console and Baidu Search Resource Platform, verify ownership, then submit:

`https://pyo2000.github.io/plus-token-justice/sitemap.xml`

Submission helps search engines discover pages, but does not guarantee indexing or ranking. Publish original, useful updates with specific titles, cite reliable sources for factual claims, and seek links from relevant organizations or news coverage.

## Editorial notes

Keep posts factual and peaceful. Cite primary documents for specific claims. Do not publish personal data, threats, or unverified recovery promises. The site does not collect visitor information or provide legal or financial services.
